Journeys
Each lane reads left to right. Screens are the same components as before, arranged by use case.
1
Host creates a game
Create → share link → leave → return once seats fill → start
1.1 Lobby — tap New game
→
1.2 Room — copy link, 1 of 4 seats
→
1.3 Comes back later — new room now listed, 3 of 4
→
1.4 Seats filled — Start game enabled
→
1.5 Game opens — host plays first
2
Invited player joins and waits
Opens link → joins → waits out other turns → notified
2.1 Link opens join — code prefilled, add name
→
2.2 Joined — waiting for host to start
→
2.3 Game started — someone else's turn
→
2.4 Leaves app — lobby nudges to turn on alerts
→
2.5 Turn arrives — full tray, board live

Nudge → setup → confirm email → badge live

→
3.2 Sheet — push, email, home screen

→
3.4 Lobby meanwhile — confirm pending
→
3.5 Confirmed — 🔔 badge live
